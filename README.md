# Fyrex Awards

نسخة أولية لموقع جوائز مجتمعية.

## ما الموجود؟
- تسجيل أي شخص بالاسم والصورة.
- اختيار فئة من 5 فئات.
- عرض المشاركين حسب الفئة.
- تصويت وترتيب حسب عدد الأصوات.
- منع التصويت المتكرر من نفس المتصفح (حماية بسيطة وليست حماية احترافية).
- تصميم متجاوب للهاتف.

## النشر على GitHub Pages
1. أنشئ Repository جديداً في GitHub، مثلاً `fyrex-awards`.
2. ارفع `index.html` و`README.md` إلى المستودع.
3. افتح Settings → Pages.
4. في Build and deployment اختر `Deploy from a branch`.
5. اختر `main` و`/ (root)` ثم Save.
6. بعد قليل سيظهر رابط موقعك بصيغة `https://USERNAME.github.io/fyrex-awards/`.

## مهم: المشاركات العامة
النسخة الحالية تحفظ البيانات في LocalStorage، أي أن تسجيل الشخص لا يظهر على أجهزة الناس الأخرى.
لجعل التسجيلات والأصوات مشتركة للجميع، اربط الموقع بقاعدة بيانات مثل Supabase (جدول nominees + votes/storage). لا تضع مفتاح service_role داخل HTML؛ استخدم فقط المفتاح anon/public مع قواعد RLS صحيحة.
